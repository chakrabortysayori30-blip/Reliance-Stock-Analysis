# Reliance Industries: Stock Price & Volatility Analysis

## Overview
This project analyzes the stock price movement of Reliance Industries from 2024 to 2026 using Python and Tableau. The analysis examines price trends, the 30-day moving average, and rolling volatility to understand market behaviour.

## Objectives
- Analyze historical stock price trends.
- Compare closing prices with the 30-day moving average.
- Measure market volatility using a 30-day rolling window.
- Visualize findings through a Tableau dashboard.

## Tools Used
- Python
- Matplotlib
- Google Colab
- Tableau

## Files
- `Reliance_Stock_Analysis.ipynb` – Python analysis
- `Reliance_Dashboard.pdf` – Dashboard export
- `Reliance_Stock_Analysis.twb` – Tableau workbook
- `reliance.csv` – Dataset

## Key Insights
- The stock reached its highest level in January 2026 and its lowest level in March 2025.
- The 30-day moving average highlighted the underlying market trend.
- Rolling volatility identified periods of higher and lower market uncertainty.
